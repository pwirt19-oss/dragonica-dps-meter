# Dragonica DPS Meter

Ein Echtzeit-DPS (Schaden pro Sekunde) Meter für Dragonica pServer.

## Features

✨ **Echtzeit-DPS Anzeige** - Sehe deinen aktuellen Schaden pro Sekunde
💾 **Gesamtschaden** - Verfolgung des Gesamtschadens
📊 **Statistiken** - Durchschnittlicher Schaden, kritische Treffer, etc.
📈 **Schadenshistorie** - Die letzten 20 Schadensereignisse
🔌 **Verbindungsstatus** - Zeige an, ob verbunden
